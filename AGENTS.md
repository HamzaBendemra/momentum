# Working on Momentum

Momentum is a public, local-first application and portable skills pack. The app has Focus, Proof, Review and Settings & Data. Read README.md and docs/ARCHITECTURE.md first.

- Use fictional examples and synthetic reproductions. Never add personal records, credentials, private source content, machine paths or real workspace backups.
- The canonical method is method/METHOD.md. Run npm run skills:build after editing it; bundled references are generated copies.
- Preserve the distinction between intentions, completion, evidence and claimed impact. Never fabricate historical records or silently rewrite a saved daily outcome when Now changes.
- Real and demo workspaces use separate databases. Restores are validated replacements with a transactional recovery copy. Markdown context exports are not backups.
- Preserve stable IDs and history when archiving, reopening or rescheduling. Align model validation, repository operations, backup validation and tests when changing persistent data. Public schema version 1 is independent of any predecessor app.
- No account, backend, telemetry, embedded AI, cloud synchronization or skill write-back in v1.
- Run npm run check before submitting app changes. Browser verification is local only; do not add browser automation to CI or deployment.
- Explain new dependencies and validate the behaviour they support. Keep unrelated changes out of a contribution.
- Avoid changing the release version merely for a documentation edit. The public version starts at 0.1.0-beta.1.
- Never publish a release, change visibility or send announcement messages without an explicit release instruction from the maintainer.
