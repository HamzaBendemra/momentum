# Community code of conduct

Treat people with respect. Critique ideas and behaviour, not identity or personal worth. Make room for different experience levels and needs. Be specific, patient and constructive when giving feedback.

Harassment, threats, discrimination, sexual harassment, deliberate intimidation, doxxing and publishing someone’s private information are not welcome. Do not put personal workspaces or sensitive information in public discussions.

These expectations apply in project Issues, pull requests, Discussions and events organised for the project. Maintainers may edit or remove harmful content, close a discussion, restrict participation, or remove a participant. They should explain a moderation decision when doing so would not expose private information or increase harm.

For a private report, use the maintainer contact link on the [GitHub profile](https://github.com/HamzaBendemra). If no private contact route is available, ask for one without posting details of the incident. Reports should include only the information necessary to understand and respond. Maintainers must not disclose reporter details unnecessarily.
