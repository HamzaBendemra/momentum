# Extraction boundary

This repository has fresh Git history. The public workspace contract and storage implementation were written independently for this release. No private Git history, live state, strategy seed, credentials, environment files, deployment connections or personal feature modules were imported.

The extraction allowlist was intentionally at symbol and pattern level, rather than copying large interdependent files:

| Reviewed predecessor material | Public reuse |
| --- | --- |
| Pure focus-priority functions: normalization, make-Now, add-Next, return-to-plan and deliberate promotion | Adapted to the public workspace model; one Now / three Next and overflow semantics retained |
| Focus-priority tests with generic milestone IDs | Rewritten public tests for limits, deduplication, strategic changes and saved outcomes |
| Calendar helpers: timezone-based Today, date addition, inactivity gap | Reimplemented with ISO calendar-date validation and focused timezone/DST tests |
| Core daily-loop interaction rules | Reimplemented explicit rollover, optional details, one-action closure and five-day reentry |
| Typography, neutral surface colours, purple accents, rail and card layout | A new focused stylesheet retaining the existing visual language |

All other source files were excluded from extraction, including the previous database, backup, cloud, authentication, private seed and data model. Financial, health, mortgage, budgeting, Mastery and Habits functionality is outside this repository. Campaigns, milestones, history, settings, onboarding, exports and the demo were authored against public schema v1.

The field-guide and repair-workshop examples were written as fictional material. New-app tests contain only synthetic records. Public source, fixtures, production output, packaged skills and full Git history are checked before publication. Media and archive contents require a separate human/agent inspection because a text scanner alone cannot establish privacy.
